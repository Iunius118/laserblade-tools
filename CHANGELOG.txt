# Change Log
[LaserBlade-Tools](https://github.com/Iunius118/laserblade-tools).

## [Unreleased]

## [1.0.1]
### Fixed
- Fix laser blade colorizer to always apply opaque colors to tools.

## [1.0.0]
### Added
- NeoForge version - Require NeoForge 26.1.2.66-beta.
- Forge version - Require Minecraft Forge 64.0.8.
- Fabric version - Require Fabric Loader 0.19.2 and Fabric API 0.150.0+26.1.2.
- Add Laser Blade Core for laser blade tool material.
- Add Laser Blade Sword, Shovel, Pickaxe, Axe, Hoe and Spear.
- Add Laser Blade Colorizer block to recolor laser blade tools.
- Add `laserbladetools:colorizer_can_change_color` item tag to specify which items laser blade colorizer can accept.
- Add furnace and blast furnace recipes for extracting laser blade cores from laser blade tools.

### Changed
- Separate data generators from NeoForge version.
- Laser blade tools colored in 1.0.0-beta.2 can have their colors repaired using laser blade colorizer.
